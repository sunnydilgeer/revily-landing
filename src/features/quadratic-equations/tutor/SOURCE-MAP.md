# Lesson 22 (Algebra A8) source map

A8 is written from the PDF/video pair `A8.1_Solving_Quadratics_By_Factorising` and the textbook's A8 page ("Solving Quadratic Equations by Factorising", with its Your Turn page). It is lesson 22 in the course (`?lesson=22`, progress key `L022`), and students see it as lesson 8 of the Algebra chapter.

There is one rung. Questions run easiest first: brackets already given, then equations already equal to 0, then a negative answer, a letter other than x, the roots of y = …, an equation that has to be made 0 first, and the pond and rug problems.

Every source answer was checked by putting it back into its equation, and the area questions by width × length (3 × 8 = 24, 4 × 10 = 40). There were no slips in the PDF or the textbook. Nothing is Higher tier: every question has x² on its own (AQA 8300 puts ax² + bx + c in bold).

The textbook's numbers are not used, so nothing looks copied (Sunny, 2 Oct). The worked example is also not the old video's x² + x = 12, which is close to the book's x² − x − 12 = 0; Sunny first asked for 16, but x² + x − 16 doesn't factorise, so it is x² + x = 20.

The working follows the textbook's four steps, each labelled above its heading ("Step 2 · factorise"): **make it 0** on the A5 board (the number boxed in purple, taken from both sides, struck out where it cancels); **factorise** with A7's three steps (factor pairs of −20, which pair adds to 1, into the brackets); **two equations**, each bracket boxed and set to 0, with the plates-and-cookies idea from the video in its ⓘ; **solve each**, undoing each bracket's number on both sides, which ends in the green answer, so the working stops there (no check step, EXPLANATIONS.md rule 7). The roots of y = … write the first row as x² − 7x + 12 = y, so the boxed y sits above the 0 that replaces it. Rows a step has finished with are greyed out.

Practice questions (`maths/practice/bank/quadraticEquations.ts`) use new equations; their AQA weights are estimates until the 2022–25 papers are counted. The readiness statement sits with Solving equations in the exam map.
