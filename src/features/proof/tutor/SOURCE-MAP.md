# Lesson 28 (Algebra A13) source map

A13 is written from Aniksha's four PDF/video pairs `A13.1_Proof_Disproof_By_Counterexample`, `A13.2_Proof_Algebraic_Equivalent`, `A13.3_Proof_Geometric` and `A13.4_Proof_Algebraic_Proof` (folder `A13_v7`). It is lesson 28 in the course (`?lesson=28`, progress key `L028`), and students see it as lesson 13 of the Algebra chapter.

| Rung | Source | App coverage |
| --- | --- | --- |
| Counterexamples | A13.1 | Video + worked example = Q1 (Mia: 2n + 1 is prime; n = 4 gives 9); Q2 to Q5c as choices, each wrong option with its own message |
| Identities | A13.2 | Video + worked example = Q1 ((x + 3)² − x² ≡ 6x + 9); Q2, Q3, Q4a, Q5a typed as the simplified left side; Q5b (400) typed; Q4b (= and ≡) and Q5c (Ella) as choices |
| Angle proofs | A13.3 | Video + worked example = Q1 (a + b + c = 180° with a parallel line and alternate angles); Q2 (36), Q3 (40), Q4a (70), Q5b (100) typed in degrees; Q5a typed as e = a + b; Q4b and Q5c as choices. Every question draws its own picture |
| Odd and even | A13.4 | Video + worked example = Q1 (n + (n + 1) = 2n + 1); Q3 (2(n + m)), Q4a (3n + 3), Q5b (2n + 1) typed; Q4b (24) typed; Q2, Q5a, Q5c as choices |

Proofs whose answer is a sentence are choices, so a phone never has to mark free writing. The angle pictures (`AnglePictures.tsx`) are drawn to the question's own angles, every label inside the picture.
