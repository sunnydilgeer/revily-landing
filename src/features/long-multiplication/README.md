# Lesson 5: Long multiplication

GCSE Foundation lesson teaching column multiplication of larger integers.

## Learning progression

1. Align ones beneath ones and tens beneath tens.
2. Build the ones partial product from right to left.
3. Interpret the tens digit by its value and place the zero.
4. Carry through multiple columns and through an internal zero.
5. Recognise multiplication in an equal-groups problem.
6. Scale a known multiplication fact using place value.
7. Complete independent, transfer and mastery questions.

Every question uses a short numeric prompt. There are no conventional
multiple-choice answer cards. The staged examples ask the learner to guess the
next step before pressing Next, matching the reversible player used in Lesson 4.

The reusable staged visual deliberately derives every frame from the selected
step, so rewinding removes all later rows, carries and totals. The opening setup
is taught as a four-step animation rather than tested before it is explained.
Estimation is not included as a taught objective; it belongs in a separate
rounding lesson.

## Curriculum examples

- Core model: `281 × 23 = 6,463`
- Repeated carrying: `347 × 26 = 9,022`
- Internal zero: `405 × 32 = 12,960`
- Theatre context: `246 × 18 = 4,428 seats`
- Known-fact scaling: `24 × 16 = 384` to `240 × 16 = 3,840`
- GCSE-style scaling: `2.96 × 3.2 = 9.472` to `29.6 × 32 = 947.2`
