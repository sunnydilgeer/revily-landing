# Lesson 8 storyboard — Enzymes

Big idea: an enzyme is a protein catalyst whose active site fits one substrate, and anything that changes that shape (too much heat, the wrong pH) slows it down. The lesson follows one reaction all the way through: saliva breaking down starch in bread, then the same reaction (amylase + starch) in required practical 4.

Anchor and route: chew bread → it tastes sweet → an enzyme in saliva did it → why it only fits starch → what speeds it up or stops it → test the effect of pH in the lab → read the results → turn a time into a rate.

Why this order: "enzyme", "catalyst" and "substrate" come first because the active site needs a substrate to fit. The active site comes before temperature and pH, so "denatured" can be explained as a change of shape. Independent, dependent and control variables and repeats with a mean are taught in the practical walkthrough before any question uses them. Results are read in the order results → pattern/optimum → rate (1000 ÷ time). "Enzyme unchanged" is tested once (B8-03).
