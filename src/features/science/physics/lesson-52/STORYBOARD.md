# Physics Lesson 52 storyboard — Reaction times

Chapter P5, Forces. Folder `physics/lesson-52`, id `P-MOT-052-P`, skill `P-REACTION`, spec 6.5.4.3.2. It owns reaction time (0.2 to 0.9 s, different for everyone), why a stopwatch does not work, the computer-based test, the ruler drop test method, and how to improve it (repeats and a mean, modelling clay, a fair test). It prepares students for the practical and does not replace it.

Big idea: a reaction time is very short, so we measure it through something that happens during it: how far a ruler falls before it is caught. A longer distance means a longer reaction time.

Flow note: what reaction time is and why it is hard to time, then the ruler drop test as a routine, then how to make it better. Calculation flow: worked mean in the frames (12, 15, 18 cm gives 15 cm) → near-identical guided item (14, 17, 20 cm) → independent item (18, 21, 24 cm).

Sections:
1. Start here (P52-01): a typical reaction time.
2. What is reaction time? (P52-02–04): definition and typical values → stopwatch problem → computer test. Checks: definition; the stopwatch.
3. How does the ruler drop test work? (P52-05–07): get ready → drop without warning → catch and read → longer distance, longer time. Checks: what the helper does; two people's results (assessment view).
4. How can you improve the test? (P52-08–10): repeat and mean → clay → fair test. Checks: a guided mean; fair test.
5. On your own (P52-11–15): an independent mean, reading two results without over-claiming, a tired driver, improving reliability, and a written description of the method.

Out of scope: the page's calculation of the fall time using v² − u² = 2as and a = Δv ÷ t (too hard, skipped as the lead brief says); the thinking-distance factors in detail (Lesson 50); caffeine or drug experiments.

Source boundary: supplied revision-guide page 219 (scope only); AQA 8464 Physics 6.5.4.3.2. All wording, numbers and diagrams are original. Draft pending teacher review.
