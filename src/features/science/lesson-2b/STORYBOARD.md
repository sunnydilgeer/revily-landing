# Lesson 2b storyboard — Magnification maths

Big idea: three numbers are linked — image size, real size and magnification. Magnification = image size ÷ real size, so if you know any two you can find the third, as long as both sizes are in the same unit.

Anchor and route: one cell seen at ×100 in the light-microscope lesson. First learn the tiny unit its size is given in (µm) → work out how many times bigger its image is → turn the rule round to find a missing real size or image size → estimate the area of a tiny part inside it.

Why this order: every calculation needs µm and mm first, so units come before the formula. Standard form sits with units because it is only a way of writing tiny sizes. "Match the units" is one frame of the magnification walkthrough, taught before its worked example, not a section after it (the old B2-12 said "first match the units" a section too early). Finding a real size or an image size needs the magnification rule already secure, so it comes next. Area only needs µm, not magnification, so it comes last as a short separate skill, keeping the magnification chain unbroken.

Limits: supplied image sizes are explicit numbers, never measurements of responsive artwork. Magnification has no unit; missing sizes carry length units. Cell sizes are examples; real sizes vary. The area model is illustrative and not to scale. Slide preparation, safe microscope technique and biological drawing belong to the practical lesson; this digital lesson does not complete required practical 1.
