# Science A/B wording variants

## What is duplicated and what is shared

Variant A is the existing six-lesson content. Variant B has independent source copies in `variants/b/lesson-1` through `lesson-6`. Each contains a lesson module and teaching frames; Lesson 1 also has its own expanded content. All 155 B teaching frames have simpler explanations. B also simplifies relevant question wording, hints, feedback, standalone teaching, worked examples and written-task guidance. Already clear questions are retained.

The interface, session engine, visual components, practical example data, skills and section navigation are shared. This is a copy comparison, not two applications or a new syllabus. All assessment targets, state/option IDs and ordering, answer keys, source/specification references, marks, rubrics, evidence rules and prerequisites match A. Whole-content fingerprints captured before implementation verify that A's content has not changed.

## Writing approach

Shorter sentences; fewer ideas in each sentence; plain meaning before building on terminology; direct links between a feature, how it helps and its job. Required GCSE terms remain. Important scientific qualifications, medical-use uncertainty and laboratory safety are not removed to meet a word limit. B reduces the overall number of teaching-body words in each lesson, but this is not a reading-age score or evidence of improved learning.

Example from Lesson 1 B: “Your body is made of cells. Each cell has smaller parts called sub-cellular structures. Each part has a job. We call this its function.”

Both variants remain AQA 8464 Foundation drafts awaiting qualified teacher review. The earlier platform/CGP writing research informs the approach; no third-party wording or images are copied. Observing intended pupils using both versions is still needed to judge comprehension.

## Routes and progress

- Default/A hub: `/preview/science`.
- B hub: `/preview/science?variant=b`.
- B lesson: `/preview/science?lesson=1&variant=b` (likewise 2–6).
- The visible A/B switch is on the hub and every lesson. Lesson switches include an `activity` target to open the same activity in the other variant. This explicit bookmark target is applied on opening/reload without awarding completion. Unknown targets are ignored. Switching does not copy submitted answers, hints or drafts.
- Menus, All lessons and next-lesson links preserve B. Existing URLs without a variant still open A. Invalid or repeated variant parameters fall back to A.
- A keeps its exact lesson IDs, content versions and storage keys. B uses `B-CELL-001-B` through `B-CELL-006-B`, content version 0.1.0. Storage keys are generated by the established engine, giving twelve isolated records. A and B reject each other's snapshots, including Lesson 1's legacy exception, which remains A-only.
- This is a manually selected local comparison, not a randomised experiment or account-level feature. There is no deployment, marking queue or production mastery change. Written work remains pending teacher review. Digital completion cannot certify a hands-on practical.
